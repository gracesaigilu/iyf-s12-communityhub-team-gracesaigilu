# CommunityHub

A community platform where members share posts, comment, and
build profiles. Built with React (Vite) as a team project for
IYF Weekend Academy Season 12.

## Features (Week 8)
- Header, Footer and Sidebar layout
- PostList showing posts from state
- CreatePost form that adds a post
- Helper function in `src/utils/` with tests

## MVP features (Weeks 8-12)
- Posts
- Profiles
- Authentication
- Comments

## Tech stack
- React (function components + useState)
- Vite
- Vitest or Jest for tests

## Getting started
1. Clone the repo
   `git clone https://github.com/gracesaigilu/iyf-s12-communityhub-team-gracesaigilu.git`
2. Go into the frontend
   `cd frontend`
3. Install and run
   `npm install`
   `npm run dev`
4. Run tests
   `npm test`

## Project structure
- `frontend/src/components/` – UI components
- `frontend/src/utils/` – helper functions and tests
- `frontend/src/exercises/` – lesson exercises per member
